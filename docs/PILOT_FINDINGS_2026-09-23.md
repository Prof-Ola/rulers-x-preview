# Pilot Validation Findings — Variant B

**Date:** 2026-09-23  
**Source:** Maze pilot report supplied by founder  
**Status:** PILOT / INSTRUMENT + MESSAGE TESTING ONLY — not product-market-fit evidence

## Sample integrity

The exported Maze report shows 8 total responses at study level, but the post-context / website-test blocks contain 4 completed responses (with 5 participants reaching the context screen). Therefore the analytically usable sample for the positioning questions is **n=4**.

This is too small and too weakly screened to support commercial conclusions. Treat all percentages as directional pilot evidence only.

## VERIFIED pilot observations

### Comprehension
Open-text answers described the product as:
- helping discover an investment option
- helping with financial decisions
- helping investors evaluate market-intelligence tools
- helping someone invest

On the category question:
- 2/4 selected Investment research platform
- 2/4 selected Market and capital intelligence system
- 1/4 also selected Market screener
- 0 selected Trading signal service
- 0 selected Portfolio management tool
- 0 selected Not sure

Interpretation: the page avoids the worst category failure (signal service), but unaided descriptions remain broad and in two cases imply investment-selection / decision assistance more strongly than the current product truth warrants.

### Trust
Open-text trust reactions:
- 2 positive (evidence-based; safe)
- 2 neutral / unresolved

Confidence exploring further:
- average 4.0 / 5
- 1 rated 3
- 2 rated 4
- 1 rated 5

Trust-increase selections:
- Data sources: 3/4
- Security explanation: 2/4
- Live market data: 1/4
- Clear methodology: 1/4
- Founder/team identity: 1/4
- Qualification/validation process: 0
- Independent reviews: 0
- Historical evidence: 0

Founder-light question:
- 3/4 would consider using the product without knowing the founder
- 1/4 would not

Open-text substitutes for founder trust included:
- clear execution/interface
- evidence of past success from reviews
- data sources
- verification and safety

### Market-scope comprehension
- 3/4 selected Multiple asset classes
- 1/4 selected Crypto first, then other markets
- 0 selected Crypto only
- 0 selected Unclear

Interpretation: Variant B communicates a broader-than-crypto future, but may under-communicate that digital assets are the *first live market*.

### Repeat-use hooks
Selections:
- Alerts: 2/4
- Risk analysis: 2/4
- Evidence behind classifications: 1/4
- Watchlists: 1/4
- None: 1/4
- Unusual market activity: 0
- Historical changes: 0
- Portfolio context: 0
- Market regime: 0

Interpretation: alerting and risk are more immediately legible than the current scanner/evidence value proposition in this tiny sample. Do not infer feature priority from n=4.

### Confusion / usefulness
Confusion answers:
- two respondents said the product was not yet clear / needed clarification
- one reported nothing unclear
- one said there should be clear understanding through Google

Usefulness answers were weak/general:
- render value appropriately
- if it brings in money
- nothing at the moment
- for investment

Interpretation: these answers suggest respondent quality / target-user fit is uncertain and the current page does not yet create a strong, concrete job-to-be-done in this sample.

## INFERENCES

1. **Founder-light is viable enough to continue testing.** 3/4 said they could consider a product without knowing the founder.
2. **Variant B is not being mistaken for a trading-signal service.** This is encouraging.
3. **Trust architecture should emphasize data provenance and security more prominently.**
4. **The proposition is still too abstract for some people.** The page explains philosophy better than immediate workflow value.
5. **Cross-asset ambition is understood, but the digital-assets-first operating reality needs to be clearer.**
6. **Current respondents may not represent the intended beachhead.** Generic answers about “investment” and “making money” indicate insufficient screening.

## UNKNOWN

- willingness to pay
- repeat usage in real life
- workflow replacement
- whether active investors react differently from general participants
- whether Variant A outperforms Variant B
- whether alerts/risk are genuinely priority features
- whether founder-light trust holds in a larger qualified sample

## Decision

**Do not change the product roadmap or pricing based on this pilot.**

Use this report to improve the study and landing-page clarity, then recruit a better-screened sample.

## Next validation gate

1. keep Variant B as the current baseline
2. tighten the landing-page explanation of the immediate job:
   - scanner directs attention
   - not investment selection
   - digital assets are the first live market
3. add stronger visible trust cues:
   - data source/provenance
   - security boundary
   - policy/qualification status
4. improve participant screening:
   - must actively invest/trade/research at least monthly
   - must use at least one market/research tool
   - tag primary asset class
5. collect 5–8 qualified Variant B responses
6. then run identical Variant A study
7. do not compare A/B until both groups are similarly screened
