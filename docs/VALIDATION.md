# Positioning validation protocol

This repository exists to test positioning and trust, not to validate investment performance.

## Variants

### Variant A
`/?variant=a`

Crypto-first:
> From 1,000+ crypto markets to the handful worth investigating.

### Variant B
`/?variant=b`

Cross-asset category, digital-assets-first:
> Know what deserves attention before you risk capital.

## First tests

Measure:
- correct understanding of what the product does
- whether users understand that attention != recommendation
- whether the evidence model increases trust
- whether founder identity is necessary for trust
- which variant is clearer
- which capability users would return for

Do not treat generic enthusiasm as product-market fit.

## Data boundary

The initial deployment uses a static, timestamped scanner snapshot.

The site must not connect directly to:
- the private RULERS-X developer database
- Aave wallet/portfolio views
- the qualification runner
- write-capable API routes
- private or signing credentials

A future public API requires its own security and product review.
